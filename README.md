# Cybersecurity Writeups & Forensics Vault

> Bóveda de evidencias técnicas, artefactos forenses y análisis profundo de amenazas.

Este repositorio funciona como el almacenamiento de evidencias crudas y reportes técnicos para los laboratorios y casos forenses expuestos en mi plataforma principal.

**Para explorar el dashboard interactivo, métricas y mi perfil completo, visita:**
[**matircode.dev**](https://matircode.dev)

---

### Core Focus & Competencias

- **Digital Forensics & Incident Response (DFIR)** en entornos Windows/Linux.
- **Análisis de Telemetría Avanzada** (Sysmon, Windows Event Logs, Auditoría de Red).
- **Documentación de Amenazas** bajo el marco metodológico global de **MITRE ATT&CK®**.

### Navegación del Repositorio

- **[`/labs`](./labs):** Investigaciones forenses individuales organizadas por caso (incluye reportes ejecutivos en Markdown, artefactos/IOCs extraídos y reportes formales en PDF).
- **[`/templates`](./templates):** Plantillas de esqueleto forense utilizadas en el CMS integrado de CSI Linux para la estructuración de informes corporativos.
